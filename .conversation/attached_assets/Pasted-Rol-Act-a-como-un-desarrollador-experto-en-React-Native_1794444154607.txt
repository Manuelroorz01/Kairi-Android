Rol: Actúa como un desarrollador experto en React Native y Expo.

Tarea: Crea una aplicación móvil funcional que sirva como control remoto por Bluetooth para el "Robot Kairi V1.0.0". La app enviará comandos de texto simples (caracteres) a un módulo ESP32 que utiliza Bluetooth Clásico.

Requisitos Técnicos:

Usa React Native con Expo.

Implementa la librería react-native-bluetooth-classic para la conexión con el ESP32.

La app debe solicitar permisos de Bluetooth y ubicación.

Diseño tecnológico: colores azul oscuro (#0A192F), detalles dorados (#FFD700) y blancos.

Estructura de la App (Pantallas):

1. Pantalla de Inicio (Conexión):

Título: "ROBOT KAIRI".

Botón "Buscar Dispositivos" que liste los dispositivos Bluetooth cercanos (el ESP32 se llamará "Kairi").

Botón para conectarse al dispositivo seleccionado.

Indicador de estado (Conectado / Desconectado).

2. Pantalla de Control (Comandos):

⚠️ PROTOCOLO DE COMUNICACIÓN ESTRICTO ⚠️: La app debe enviar únicamente estos caracteres de texto (String) por Bluetooth al presionar los botones correspondientes. No agregues botones de movimiento, solo los colores:

Botón Rojo -> Envía el carácter '1'

Botón Azul -> Envía el carácter '2'

Botón Verde -> Envía el carácter '3'

Botón Amarillo -> Envía el carácter '4'

Botón Aqua (Cian) -> Envía el carácter '5'

Botón Rosa (Magenta) -> Envía el carácter '6'

Botón Apagar -> Envía el carácter '7'

La interfaz debe mostrar los botones de colores en una cuadrícula (grid) y un botón grande al final que diga "APAGAR".

Incluye un botón de "Desconectar" que cierre el socket Bluetooth.

3. Pantalla de Información (Manual):

Un menú con pestañas para ver la información del robot (sin botones de acción, solo texto e imágenes):

Componentes: ESP32, Luces LED RGB, Batería LiPo 3.7V 800mAh, Módulo Step-Up, Pulsadores, Estructura (Cabeza, Cuerpo, Patas).

Características: Dimensiones (15 x 12 x 15 cm), Peso (0.75 kg), Batería (LiPo 3.7V / 800mAh), Carga (USB-C). (NO incluir velocidad ni Wi-Fi).

Cuidados: Mantener seco, Evitar golpes, No exponer a altas temperaturas, Usar cargador original, Limpiar con paño suave.

Descripción: "El Robot Kairi es un dispositivo interactivo de escritorio controlado manualmente. Cuenta con iluminación LED RGB y un sistema de alimentación autónomo mediante batería recargable. Su diseño está optimizado para el aprendizaje de robótica básica."

Entregable: Genera el código completo (App.js, componentes de pantalla, lógica de Bluetooth) y asegúrate de que la función de envío de datos utilice el método correcto para enviar caracteres (String) al puerto serial Bluetooth del ESP32.
