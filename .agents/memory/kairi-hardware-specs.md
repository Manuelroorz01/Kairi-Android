description: Propósito y especificaciones físicas vigentes para el manual y las descripciones de Kairi.
---

Robot Kairi ya no tiene pulsadores ni patas. Usa una batería desmontable de 9 V y no una batería de litio. Las dimensiones y el peso quedan pendientes. Se puede usar cualquier cargador USB-C.

El propósito de Kairi es conectar con las personas mediante su código de colores; no describirlo como un diseño optimizado para aprender robótica.

**Why:** el usuario corrigió tanto las especificaciones físicas como el propósito comunicado del robot; la información anterior ya no aplica.

**How to apply:** conserva estos datos en el manual y otras descripciones del producto. No vuelvas a incluir pulsadores, patas, batería de litio ni la descripción de aprendizaje; mantén dimensiones y peso como pendientes hasta recibir los valores nuevos.
